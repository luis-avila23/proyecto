Verdadero valor de daño

Ok, antes de revisar las mejoras de cada tipo de arma

se debe conocer cual es el verdadero valor de daño del arma

como se hace eso te preguntaras, pues se hace con una sencilla formula:

Ataque Bruto / Modificador del Arma = Ataque Base

Ahora, no te asuste ya te explico

el ataque bruto es el valor de ataque del arma que te muestra el juego

y el modificador de daño de cada arma? son estos:

  • Gran espada = 4.8
  • Espada y escudo = 1.4
  • Espadas dobles = 1.4
  • Martillo = 5.2
  • Lanza = 2.3
  • Ballesta ligera = 1.2
  • Ballesta pesada = 1.2
